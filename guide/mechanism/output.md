# 产出数量

产出数量影响着收获作物时产物的数量。

## 产出数量与产物数量

设 `output` 为种子袋的产出数量，`E = max(0, output - 1)`。收获时，每种产物实际掉落的
数量 `count` 按下面的规则计算：

```text
count = 1 + floor(E / 5) + Bernoulli(E mod 5 / 5)
```

其中 `Bernoulli(q)` 表示以概率 `q` 成功并额外获得 `1` 个产物，失败则获得 `0` 个。

因此，每种产物的期望数量为：

```text
E[count] = 1 + floor(E / 5) + (E mod 5) / 5
```

即每 `5` 点产出数量提供 `1` 个保底产物，剩余 `0 ~ 4` 点分别提供
`0% ~ 80%` 的额外 `1` 个产物概率。

> 产出数量是 **每种产物分别计算**的，不是所有产物共享总数。如果种子有 `R` 种产物，
> 一次收获的总物品期望为 `R * E[count]`，每种产物都会获得数量为 `count` 的独立堆叠。
> 另外，`output = 0` 时 `E = 0`，实际仍会产出 `1` 个。
