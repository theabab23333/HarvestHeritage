# 生长速度

生长速度影响着作物受到随机刻后**进入下一阶段的概率**。  

_生长速度越大，进入下一阶段的概率越高_。~~**但是还是得等随机刻**~~。

## 生长速度与生长阶段

设：

- `N` 为种子的成熟生长阶段（`SeedInfo.stage()`）。
- `s` 为作物架当前生长阶段，刚种下时 `s = 0`。
- `speed` 为种子袋的生长速度。

每次随机刻，若作物下方的所需方块满足条件且 `s < N`，模组会执行一次
`random.nextInt(3) < speed` 判定，判定成功则生长阶段 `s` 增加 1。

因此，单次随机刻进入下一阶段的概率为：

```text
p = min(max(speed, 0), 3) / 3
```

也就是：

| 生长速度     | 每次随机刻进阶概率 |
|--------------|--------------------|
| `speed <= 0` | `0`                |
| `1`          | `1/3`              |
| `2`          | `2/3`              |
| `speed >= 3` | `1`                |

> 注意：判定使用 `random.nextInt(3)`，所以生长速度超过 `3` 后概率已经达到上限，
> 继续提高生长速度不会让单次随机刻多次进阶。配置文件中的生长速度上限只限制数值范围，
> 不改变这一概率上限。

从阶段 `s` 生长到成熟阶段 `N`，需要成功进阶 `N - s` 次。每次随机刻的进阶判定相互独立，
因此：

```text
期望随机刻次数 = (N - s) / p
               = (N - s) * 3 / min(speed, 3)    (speed >= 1)
```

在 `k` 次随机刻内成熟的概率服从二项分布：

```text
P(成熟 | k 次随机刻) = P(X >= N - s)
                     = Σ(i = N - s .. k) C(k, i) * p^i * (1 - p)^(k - i)

X ~ Binomial(k, p)
```

若随机刻速度为 `R`（默认 `R = 3`，即每个子区块每游戏刻随机选取 3 个方块），
单个方块每游戏刻被随机刻选中的概率为 `R / 4096`，那么期望现实时间为：

```text
期望游戏刻 = (N - s) / p * 4096 / R
期望秒数   = (N - s) / p * 4096 / (20 * R)

默认 R = 3 时：
期望游戏刻 = (N - s) / p * 1365.33
期望秒数   = (N - s) / p * 68.27
```

例如，`N = 4`、`speed = 2` 时，`p = 2/3`，从阶段 `0` 开始成熟需要
`4 / (2/3) = 6` 次随机刻期望；在默认随机刻速度下约为 `8192` 游戏刻，
即约 `409.6` 秒（不考虑方块条件未满足或区块未加载的时间）。
