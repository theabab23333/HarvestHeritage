## 开始

从打草开始的~~坐牢之旅~~。

> ~~模组作者小时候玩 GTNH ，被里面 IC2 杂交调教好了写的。~~

1. 合成除草剪打草，获取未知种子
2. 未知种子用放大镜扫一下合成已知种子。
3. 已知种子和纸合成种子袋。
4. 用四根木棍合成作物架。
5. 种子袋种作物架上。
6. 等他成熟，长不大可能是条件没符合，看看 JEI。
7. 杂交什么的装个 GuideME 吧，有点复杂了，机制都写里面了。

> ~~我觉得未知种子、已知种子很脱裤子放屁，以后删了~~
